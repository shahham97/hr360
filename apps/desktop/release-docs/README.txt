HR360 Enterprise Client - Release Readme
================================================================================
Product: HR360 Enterprise Client
Version: 1.0.0
Release Channel: Stable

1. OVERVIEW
HR360 is an enterprise human resources, attendance, biometric synchronization,
and payroll operations platform designed for secure multi-organization use.

2. SYSTEM REQUIREMENTS
- Operating System: Microsoft Windows 10 (64-bit) or Windows 11 (64-bit)
- Processor: 1.6 GHz dual-core or faster 64-bit processor
- Memory (RAM): Minimum 4 GB RAM (8 GB recommended)
- Disk Space: 500 MB free hard disk space
- Network: Stable broadband connection with HTTPS support (TLS 1.3)
- Display: 1280 x 800 minimum screen resolution (1920 x 1080 recommended)

3. INCLUDED MODULES & FUNCTIONALITY
The HR360 desktop application provides unified access to the following 10 enterprise modules:
- Executive Dashboard: Real-time workforce metrics, departmental headcounts, and key operational alerts.
- Employee Lifecycle: Employee directory, profile records, emergency contacts, qualifications, and document vaults.
- Biometrics & Attendance: Device integration, daily punch logging, shift assignments, and late/early calculations.
- Leave Management: Leave balance tracking, entitlement accrual, policy configurations, and approval workflows.
- Payroll Engine: Statutory salary calculations, tax computations, deduction schedules, and bank transfer export files.
- Payslip Designer: Template management, secure dynamic payslip rendering, and bulk PDF generation.
- HR Certificates: Standard experience, increment, and service certificate templates with tamper-evident verification codes.
- Performance & Benefits: Review cycles, KPI/goal tracking, benefit program administration, and appraisal matrices.
- Recruitment & ATS: Job requisitions, applicant pipeline management, interview scheduling, and hiring workflows.
- System Audit & Security: Tamper-evident audit logs, device authorization management, and active session security.

4. SUBSCRIPTION TIERS (HIGH-LEVEL SUMMARY)
- Starter: Designed for small organizations up to 50 active employees.
- Growth: Designed for expanding teams up to 250 active employees with advanced leave policies and shifts.
- Enterprise: Tailored for high-scale enterprises with custom employee quotas, dedicated audit retention, and custom workflows.

5. AUTOMATIC UPDATE BEHAVIOR
HR360 automatically checks for certified software updates every 4 hours.
When an update is released:
- A non-intrusive notification appears in the top navigation bar.
- You may choose to update immediately or install on next application exit.
- Critical security and protocol updates may require installation prior to continuing operations.
- Application updates strictly preserve your local settings and secure sessions.
